Задание №2.Контекст.Возраст моллюска абалон (морское ушко) определяют для оценки его качества, пищевой ценности и безопасности. У более старых особей мясо становится жестким, а вкус — менее нежным, чем у молодых. Кроме того, определение возраста необходимо для контроля за выловом, так как этот вид растет медленно и часто подвержен угрозе исчезновения. Этапы:созданы модули для подсчета данных,загрузки,предобработки,проверки.Созданы графики для визуализацуии,посчитана ошибка.Выведена проверка на пустые строчки.Сложность алгоритма 0(n).
