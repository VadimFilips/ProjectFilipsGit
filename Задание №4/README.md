Набор данных Titanic.Используемые классификаторы: Классификатор градиентного бустинга, Классификатор CatBoost, Классификатор Extra Trees, Light Gradient Boosting Machine,SVM - линейное ядро. Использованы  различные стратегии перевзвешивания классов ( oversampling, undersampling). Использованы GridSearchCV для подбора гиперпараметров.
