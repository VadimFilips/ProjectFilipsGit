Датасет содержит данные о продолжительности жизни и сопутствующих показателях для различных стран за период 2000-2015 гг.
Основные характеристики:
Количество наблюдений: более 2000 записей.
Временной охват: 2000-2015 годы.
География: различные страны мира.
Типы стран: развивающиеся и развитые.
Ключевые показатели.
В датасете представлены следующие метрики:
Ожидаемая продолжительность жизни;
Взрослая смертность;
Детская смертность;
Потребление алкоголя;
Процент расходов на здравоохранение;
ВВП на душу населения;
Уровень образования;
Индикаторы вакцинации;
Показатели питания (ИМТ). 
Используемые регрессоры: Extra Trees, CatBoost, Gradient Boosting, Lasso,Dummy,Huber. Использованы GridSearchCV для подбора гиперпараметров.Добавлены гипотезы,критерии оптимальности выбора параметров. Проведен анализ метрик между собой и визуализированы результаты.
