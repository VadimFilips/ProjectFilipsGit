Датасет содержит исторические данные о землетрясениях, собранные Геологической службой США (USGS) — ведущим мировым учреждением по мониторингу сейсмической активности.

Период данных
Охватывает значительный временной диапазон — с 1965 по 2016 год. Это позволяет анализировать долгосрочные тенденции сейсмической активности.

Объём данных
Содержит более 23 000 записей о землетрясениях по всему миру.

Проведен Анализ EDA, построены гипотезы. Решена задача анализа временного ряда при помощи 5 подходов ML- LSTM, GRU, TRANSFORMER, CNN, АВТОЭНКОДЕР. Произведен поиск аномалий. Созданы графики ошибок прогнозирования, метрик качества обученной модели и важности признаков.
